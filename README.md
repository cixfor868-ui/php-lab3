# Лабораторная работа №3 по PHP

Автор: Ласточкин О.О., группа 25-ИСТ-3.

Репозиторий учебного проекта по дисциплине «Программирование на языке PHP»:

* работа с git: локальный и удалённый репозиторий, ветки `Feature/1` и `Feature/2`, слияние через Pull Request;
* автозагрузка классов Composer (PSR-4, пространство имён `App\` → папка `src/`);
* регистрация и авторизация пользователей, хранение настроек (цвет фона и шрифта) в БД MySQL;
* передача настроек клиенту в cookie и автоматический вход при повторном открытии сайта.

## Запуск

1. Open Server Panel 6, проект `lab3.local` (Nginx, PHP 8.3, MySQL 8.0).
2. `composer dump-autoload`
3. Создать таблицу: `source sql/schema.sql` в клиенте MySQL.
4. Открыть http://lab3.local/
